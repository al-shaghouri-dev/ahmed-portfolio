# موقع أحمد محمد علي شخاشيرو

موقع شخصي عربي متجاوب، بتصميم داكن ولمسات ذهبية، وصفحة عامة ولوحة إدارة منفصلة بتسجيل دخول حقيقي عبر Supabase.

## الملفات
- `index.html`: الموقع العام ولوحة الإدارة.
- `config.example.js`: قالب إعداد الاتصال.
- `supabase-schema.sql`: إنشاء جدول المحتوى وسياسات القراءة/التعديل ومساحة تخزين الصور.
- `config.js`: تنشئه أنت بنسخ `config.example.js` وتعبئة بيانات Supabase.

## قبل النشر
1. أنشئ مشروعًا في Supabase.
2. من SQL Editor نفّذ محتوى `supabase-schema.sql` مرة واحدة.
3. من Authentication > Settings عطّل التسجيل العام للمستخدمين (Disable signups).
4. أنشئ حساب دخول إداريًا واحدًا من Authentication > Users، ببريدك وكلمة مرور قوية. لا ترسل كلمة المرور لأي أحد.
5. انسخ `config.example.js` إلى ملف اسمه `config.js` في نفس مجلد `index.html`.
6. في `config.js` ضع Project URL وPublishable/anon key من إعدادات مشروع Supabase. هذه مفاتيح واجهة عامة؛ لا تضع `service_role` أو أي مفتاح سري في الموقع.
7. ارفع الملفات الثلاثة `index.html`, `config.js`, و`README.md` إلى مستودع GitHub. لا حاجة لرفع `config.example.js` أو SQL كي يعمل الموقع، لكن احتفظ بهما للنسخ الاحتياطي.
8. اربط المستودع مع Vercel وانشره. إعداد المشروع لا يحتاج Build Command؛ الموقع HTML ثابت. اترك Output Directory فارغًا أو استخدم `.` إذا طلبها الإعداد.
9. افتح رابط Vercel ثم اضغط «إدارة الموقع» أسفل الصفحة وسجّل الدخول.

## لوحة الإدارة
- تعديل البيانات العامة والنبذة والهدف والبريد والهاتف.
- تغيير اللون الأساسي ولون الخلفية.
- وضع رابط صورة شخصية أو رفع صورة إلى Supabase Storage.
- تعديل الخبرات والمشاريع والمهارات والتعليم بصيغة JSON.
- حفظ التعديلات على قاعدة البيانات لتظهر للزوار من أي جهاز.
- تنزيل نسخة احتياطية JSON واستعادتها.

## تنبيهات مهمة
- لوحة الإدارة لا تعمل بشكل آمن قبل إكمال إعداد Supabase وإنشاء حساب إداري.
- لا تنشر بيانات تواصل أو خبرات أو تواريخ لا تريد إتاحتها للعامة.
- بيانات الخبرات والمشاريع الافتراضية مختصرة؛ راجع المسميات والتواريخ والأوصاف قبل النشر. لا تعتبر نماذج المشاريع الافتراضية مشاريع مكتملة ما لم تكن كذلك.
- البريد ورقم الهاتف موجودان وفق المعلومات التي زوّدتني بها سابقًا؛ عدّلهما إن رغبت قبل النشر.
- احتفظ بملف SQL ونسخة احتياطية من المحتوى.
